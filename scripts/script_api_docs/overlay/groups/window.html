Second windows for a desktop application: a tool window beside the main one, a document per window. Window 0 is the main window; window.setTitle(0, …) and window.setSize(0, …) are app.setTitle and app.setSize, and close(0) is refused with a pointer to app.quit. Only an exported application has windows to give: in the editor open answers 0, and so it does on a renderer without a path into a second window (Software and Metal have one). A width or height of 0 or less opens at 640 × 480.
