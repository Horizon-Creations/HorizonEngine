horizon.log writes one line at Info level to the editor's Console and to HorizonEngine.log, in the editor and in a packaged game alike. In the editor the line is prefixed with the project's script language, for example [Lua]. The message must be text. Lua turns a number into text on its own, and anything else (nil, a table, a boolean) is an error. Python accepts only a str, so pass numbers through an f-string or str(). The language's own print writes to standard output only, which the Console does not show.
