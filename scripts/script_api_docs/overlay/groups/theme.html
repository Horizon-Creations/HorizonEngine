The colours and text size of every widget. A Theme asset carries a light and a dark set of colour roles; set switches the asset, setMode picks between its two sets. Widgets that name their own theme in the designer keep it.

  • Mode names are exact: "Light", "Dark" or "System". Anything else, including "dark", is ignored with a log line.
  • Preference and mode are two answers. getPreference returns what was asked for, including "System"; getMode returns what is on screen, only ever Light or Dark. Store the preference, show the mode (see the example under setMode). Where the desktop reports nothing, System resolves to Dark.
  • Font scale is clamped to 0.5 … 3: setFontScale(5) reads back 3, 0.1 reads back 0.5.
  • set answers false for a path that does not load and for a Theme asset whose JSON cannot be read; the current theme stays.
