Other programs on the machine. run and openUrl need the project permission Run other programs; which needs none, so a script can find out what is installed before anyone decides to allow it.

  • run blocks the frame until the program ends or the timeout kills it; a timeout of 0 means 30 seconds. It returns four values, ok, exitCode, out, err: ok is true for exit code 0, out and err are the complete output. A program that could not be started gives exit code −1. Nothing goes through a shell.
  • openUrl hands the address to the desktop (browser, mail client, file manager) and answers false for an empty one or when the desktop refuses it. which answers the full path, or "".

Known issue (build 7d49d44f): from Lua and Python run passes no arguments. The argument list is a list pin. A Lua table or Python list is rejected (bad argument #2 … string expected, TypeError); a string is accepted and dropped. So horizon.process.run("git", "status", 10) runs git with no arguments at all. From a script only programs that need no arguments work; everything else belongs in a HorizonCode graph for now.
