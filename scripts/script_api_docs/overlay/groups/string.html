Text functions with the same results a HorizonCode graph gets. Three rules decide most surprises:

  • Positions count from 0, also in Lua, whose own string.sub and string.find count from 1. find returns −1 when the piece is not there.
  • Lengths and positions are bytes. Text is UTF-8: letters, digits and punctuation from plain ASCII take one byte, an accented or non-Latin letter two to four. length("ä") is 2, and a substring can cut such a letter in half. toUpper and toLower change only A to Z.
  • Comparisons are exact. equals, contains, find, startsWith and endsWith are case-sensitive; lower both sides first when case should not matter.

An empty piece is found everywhere: contains(s, "") is true and find(s, "") is 0, while replace(s, "", x) returns s unchanged. A negative start in substring uses up part of count, so substring("hello", -2, 4) is "he". toNumber reads the number at the start of the text and ignores the rest: "3.5abc" gives 3.5, " 42 " 42, "1e3" 1000 and "0x10" 16. The result is a 32-bit float, exact for whole numbers only up to 16,777,216.
