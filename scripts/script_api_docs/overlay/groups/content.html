Loading assets ahead of time. Everything a scene uses is loaded with it, so these calls are for what a scene does not name yet: the level behind a door, a mesh a script will spawn. An asset is named by its path inside the project's Content folder, as the Content Browser shows it, for example Meshes/Crate.hasset. load reads the file right away, in the calling frame, so call it before the moment the asset is needed.

load on an asset that is already in memory returns true without reading it again. A path that does not exist returns false and logs where it looked. unload returns false the second time. typeName answers only for a loaded asset, with names like StaticMesh, Texture or Material, and an empty string otherwise.
