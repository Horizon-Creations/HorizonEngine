Queries against the physics world and pushes on its bodies. Without a running physics world (edit mode, a world with no bodies built) every query misses, every push returns false and every read is zero. Units are metres, seconds, newtons and kilograms; the one exception is spin, which is in radians per second.

  • Hits from Lua/Python. raycast and the four casts return ten values: hit, entity, px, py, pz, nx, ny, nz, distance, layer. On a miss they are false and zeros. The flat horizon.raycast returns a table / dict (entity, x, y, z, nx, ny, nz, distance, no layer) or nil / None. The direction does not have to be normalised.
  • A ray started inside a collider hits that collider at distance 0. A ray from a character's own position therefore finds the character. Start it outside the own capsule (a step ahead, see the example below) or give the character its own collision layer and leave that bit out of the mask.
  • Shape casts report the centre, not the contact. For sphereCast, boxCast and capsuleCast, point is where the shape's centre stopped (a 0.25 m sphere dropped on a floor at y = 1 reports y = 1.25), which is what a camera boom or a placement check wants. The shape casts ignore trigger volumes; raycast and the overlaps see them.
  • Layer masks are bitfields: bit N is collision layer N, 65535 (or -1) is every layer, 0 sees nothing. The layer names are in Project Settings under Collision Layers.
  • World and local. Every point a query returns is in world space, and so are the positions of addForceAtPosition / addImpulseAtPosition. setPosition and setPositionAndReset take a local position, like horizon.setPosition: for a child entity the value is relative to its parent. Joint anchors are local to their own entity.
  • Forces (addForce, addImpulse, addTorque, the two …AtPosition) need a Dynamic rigid body and return false with a log line on a static or kinematic one, so also on a character. A character moves through Locomotion.
  • setVelocity addresses the character controller when there is one, otherwise the rigid body. On a character with a Movement component the next frame overwrites the horizontal part with whatever locomotion.move asked for (nothing = standing still), so use setVelocity on characters only without one.
  • setGravity changes gravity for rigid bodies in the whole world. A character falls by its own Character Controller gravity and does not follow it.

Joints tie two rigid bodies together; the entity passed first owns the joint, and only it reports hasJoint. A type outside 0–4 becomes Fixed. setJointMotor works on a Hinge or Slider only and returns false otherwise. A joint made at runtime is written to the owner's Joint component, the same component the editor places, and removeJoint or a break removes it again.

▲

List results do not reach Lua or Python. overlapSphere, overlapSphereLayers, overlapBox, overlapCapsule, raycastAll and pollJointBroken return scalar zeros there instead of lists (see Lists, measured on build 7d49d44f). pollJointBroken still empties the queue, so a script calling it takes the events away from a HorizonCode graph that polls the same queue. Until this is fixed, use these from HorizonCode, and in scripts react to contacts with onBeginOverlap on a trigger volume.
