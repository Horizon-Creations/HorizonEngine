Small settings that outlive the game: volume, the last folder, “don't show this again”. Each value sits under a key of your choosing in Prefs.json in the game's data folder (see File System), shared by every script and graph of the game. Every set and remove writes the file at once. Progress belongs in a save instead.

  • A getter returns its fallback when the key was never set or holds another type: getBool on a number gives the fallback, not true. has tells a missing key from one that is set to the default value.
  • Numbers are stored with about seven significant digits: setNumber("volume", 0.1) writes 0.10000000149011612, and whole numbers are exact only up to 16 777 216. Keep ids and large counts as strings.
▲

Known issue in the editor: preferences follow you into the next project. The file is read once per run of the program. After opening another project in the same editor session, the getters still answer with the first project's preferences, and the next set writes all of them into the new project's Prefs.json (measured on build 7d49d44f). Restart the editor after switching projects before you play. An exported game has only one project and is not affected.
