The game clock. It advances once per frame, and every query gives the same answer for the rest of that frame. In the editor it runs only during Play and starts from 0 each time. For the time of day use Date and Time; to be called back later, use a Timer.

deltaTime and elapsed are scaled: they follow the time scale and stand still while the game is paused or in a hit stop. unscaledDeltaTime and unscaledElapsed follow real time, which is what a pause menu or a UI animation needs.

Three separate controls stop or slow the clock, and effectiveScale is their result:

  • Time scale (setTimeScale), limited to 0…5. A larger value becomes 5, a negative one 0.
  • Pause (pause / resume). It also silences input actions, except the ones with Fires while the game is paused ticked in the Input asset. Tick it on the key that opens the pause menu, or that key cannot close it again. All scripts and graphs share one pause, so a resume anywhere lifts a pause from anywhere. The pause the window sets when it loses focus is separate; resume cannot lift it.
  • Hit stop (hitStop): a freeze for a stretch of real time. Input keeps arriving, and isPaused stays false.

Pause and hit stop leave the time scale alone, so the game resumes at the speed it had. When a game loads another scene, the scale goes back to 1 and the script pause and any hit stop are lifted; elapsed and frameCount keep counting.
