The wall clock: calendar date and time of day in the time zone of the computer the game runs on. Unlike Time it keeps going through pauses and has nothing to do with frames. A point in time is a number of seconds since 1 January 1970 (the Unix epoch), which is what now returns and every other function takes. format uses strftime patterns: %Y-%m-%d, %H:%M, %A for the weekday name. An empty pattern, or a result longer than 511 bytes, gives an empty string. weekday counts from 0 for Sunday.

▲

Known issue: accurate only to about a minute. The seconds pass through the engine as a 32-bit float, which today can only hold multiples of 128. now is therefore up to 64 seconds off, and so are second, minute and format with %S or %M, also when you pass in an exact time. The hour, day, month, year and weekday are only wrong in the minute around a change. Until this is fixed, take a time that has to be exact from the language: os.time() and os.date() in Lua, time.time() and datetime in Python.
