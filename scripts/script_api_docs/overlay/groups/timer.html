A timer calls back instead of waiting. after and every return a handle at once and the script carries on; when the time is up the engine calls onTimer(self, handle) (Python on_timer, see Callbacks) on every script instance, and fires the GameInstance's On Timer event. Keep the handle and compare it, because the other scripts' timers arrive too.

  • Timers run on real time: pause, slow motion and hit stop do not stretch them. To wait in game time, count horizon.time.deltaTime() in onUpdate.
  • Handles count up from 1. 0 means the timer did not start: the interval was shorter than 0.001 seconds or not a number, or 64 timers were already running.
  • A timer belongs to the session, not to the script or entity that started it. Destroying the entity or loading another scene does not stop it; stopping Play or quitting the game does. cancelAll stops every timer, other scripts' and the GameInstance's included. To stop only your own, use cancel(handle).
