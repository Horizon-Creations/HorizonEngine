The sky, the day-night cycle and the weather look of the scene: every field of the Environment component on the Sky entity, which the Environment window adds. If a scene carries more than one Sky, these functions and the renderer both use the first. The table below is generated from the engine's own field list, so it always has every field there is.

  • Colours take four numbers. A color field is set from Lua and Python with r, g, b, a: horizon.env.setSunColor(1, 0.8, 0.6, 1). The fourth number is ignored, but it has to be there: with three, Lua raises bad argument #4 and Python IndexError. The getters return four numbers with alpha always 1. int fields need a whole number (1.7 is an error in both languages); bool fields accept true/false or, in Python, 1/0.
  • Nothing is clamped. A setter stores exactly what it is given: a time of day of 1.7, a negative fog density or a cloud quality of 9 read back unchanged. Stay inside the ranges the descriptions give. Time of day is wrapped into 0 to 1 only when Auto Advance moves it on.
  • Time of day needs the cycle switched on. setTimeOfDay only moves the sun while DayNightCycle is true; the Details panel switches that on for you when you drag the slider, a script does not. For a clock that runs by itself set AutoAdvance as well: with a CycleSeconds of 10, one second moves the time by 0.1, and with MoonPhaseAuto the moon phase moves one cycle per MoonCycleDays days.
  • Weather. A Weather component writes six of these fields (cloud coverage, fog density, wind speed, rain, snow, wetness) toward its preset, blending over its transition time. It backs off a field as soon as its value differs from the last value Weather wrote, so a value a script sets stays until a new preset is selected, which takes all six back. The lightning Flash is rewritten every tick. Every other field is never touched by Weather.
  • No Sky entity (removed in the Environment window): every getter answers 0, false or black, and every setter does nothing. A time of day of 0 then does not mean midnight.
