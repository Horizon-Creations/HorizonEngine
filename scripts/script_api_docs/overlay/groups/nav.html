Sends an entity with a Nav Agent component across the scene's baked NavMesh. The agent walks by itself once moveTo has started it; if it has a Character Controller it is steered through it, so it collides and falls like the player. Every call on an entity without a Nav Agent does nothing, returns false / -1 and logs has no NavAgentComponent.

  • Destinations are world positions, also for a parented agent, and they have to lie on the walkable surface: a point beside the mesh or a few metres above it is refused. For a target that moves, call moveTo again; each call plans a new route from where the agent stands.
  • moveTo plans the route inside the call, so its false is final: no NavMesh, destination off it, or no connection. A refused call also stops an agent that was already walking, and the log line says which of the reasons it was.
  • After arrival isMoving and hasPath are false and remainingDistance is -1, the same as after stop or a refusal. It never reads 0, so test "arrived" with isMoving. The agent stops within the Nav Agent's Stopping Distance of the target.
  • setSpeed is the agent's own speed (default 3.5 m/s), not the Movement component's Max Speed. A negative value becomes 0, and an agent at speed 0 stands still while isMoving stays true.
