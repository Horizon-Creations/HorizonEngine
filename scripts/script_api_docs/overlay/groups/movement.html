What a character is doing right now, read from its Character Controller. Queries only; to make a character move use Locomotion. An entity without a Character Controller reads 0 and false, without a log line.

  • All speeds are metres per second. speed is horizontal only (falling is not running), verticalSpeed is positive while rising.
  • forwardAmount and rightAmount are the same horizontal velocity split along the character's facing, also in metres per second, not a fraction: a character strafing right at 5 m/s reads rightAmount 5. Divide by speed for −1…1, and guard against a speed of 0. Forward is the entity's −Z axis turned by its yaw.
  • isGrounded is the same answer as physics.isGrounded and the flat horizon.isGrounded, and the one locomotion.jump checks.
