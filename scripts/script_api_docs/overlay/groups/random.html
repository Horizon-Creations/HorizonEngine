One random generator for the whole game, shared by every Lua and Python script and every HorizonCode graph. It starts from the same built-in seed at every launch, so a game that never calls seed draws the same numbers every time it starts. Seed it once at start: from the clock when every run should differ, from a constant when a bug should happen again.

Because it is shared, a seed restarts the sequence for everyone, and another script drawing in between changes the numbers you get. A repeated run matches only if the same scripts draw in the same order. Lua's math.random and Python's random module are separate generators and seed does not touch them.

All five are actions, because every call draws a new number (see Actions and queries). range can return min but not max; rangeInt includes both ends. Either one swaps the bounds when max is smaller than min. chance treats anything below 0 as 0 and anything above 1 as 1.
