Lines, spheres and boxes drawn into the 3D view, to see what a script is doing: where a ray went, what an overlap covered. A shape stays for seconds; 0 draws it for one frame, so a shape that follows something moving is drawn again every frame from onUpdate. The time counts down only while the game runs. The color is red, green and blue from 0 to 1; its alpha is ignored. clear removes every shape, including the ones other scripts drew. Debug shapes appear in a packaged game too, so take them out, or put them behind a flag of your own, before you ship.

▲

Known issue: four numbers per position. The positions of line, sphere and box are declared as colors, so Lua and Python read four numbers for each one. Pass a fourth number (it is ignored) after every x, y, z: line takes 13 arguments, not 10. With too few, Lua reports bad argument #11 and Python raises IndexError. The signatures below show the extra number as _.
