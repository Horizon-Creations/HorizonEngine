Steering a character's animation from gameplay: the parameters its animator state machine tests, and the weights of its animation layers. Parameters live on the entity's Animator State Machine component, layers on its Animation Layers component; without the component the setters do nothing and the getters answer 0 or an empty string.

  • Parameters are numbers. setParam takes a float. A yes/no parameter is 1 or 0: in Lua setParam(e, "Grounded", true) is an error (number expected, got boolean), Python turns True into 1. A name the state machine asset never declared is created, not rejected, so a typo writes a parameter nothing reads. getParam answers 0 for a name that was never set.
  • Layers are found by name, first match. Two layers may share a name; every function then acts on the first of them. setLayerWeight clamps to 0 to 1. playLayer restarts that layer's own playhead and leaves its weight alone.
  • notifiesOf and layerNames return lists, which scripts cannot receive yet: from Lua and Python they answer an empty string (see List results). Notifies themselves reach a script as the onAnimationNotify callbacks. notifiesOf loads the clip if it is not in memory.
