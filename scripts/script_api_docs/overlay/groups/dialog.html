The operating system's own message boxes and file pickers. Every one of them blocks: the frame stops until the person answers, so a game keeps them for what really has to be read or chosen first. No permission is needed.

  • Choosing is the permission for the fs rows: a path returned by openFile or saveFile, and everything inside a folder from pickFolder, may be read and written with an absolute path from then on, even when the project does not allow files outside the project. It does not open db.open or print.toPdf, see Database.
  • An empty path means cancelled, and it is also the answer when the picker fails. A picker left open for five minutes is given up on and answers empty as well.
  • message kind 1 is a warning, 2 an error, anything else information. confirm returns true for the first button; empty labels become "OK" and "Cancel", Return takes the first button and Escape the second.
  • Hidden runs (HE_HIDDEN_WINDOW, headless exports and tests) show no box: message writes its text to the log and confirm answers false. The three pickers do not check for a hidden run, so keep them out of one.
