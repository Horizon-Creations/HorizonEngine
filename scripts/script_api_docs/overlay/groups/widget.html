Live instances of Widget Designer assets. A widget is addressed by the id that horizon.createWidget(path) returns (0 when the asset does not load); showing, hiding and destroying it are the flat showWidget, hideWidget and destroyWidget. A new widget starts hidden until showWidget (or showModal, openPopup, window.show) puts it on screen. Widgets live outside the entity world, so a widget id is not an entity id, and in an exported game a script and a HorizonCode graph share the same widgets.

  • Always pass the widget. Several descriptions say “leave Widget unwired” for the calling widget's own. That is a HorizonCode graph living in the widget; a script has no widget of its own, and 0 answers false or 0.
  • Scripts receive none of the widget events. On Row Bind, On Selection Changed, On Dismissed, On Right Clicked, On Animation Finished and On Clip Finished go to the widget's own HorizonCode graph only. Neither are there Set External, Call External or Bind Event for scripts. In practice: a script can size, select and scroll a ListView, but its rows are filled by the row widget's own graph; a script notices a closed dialog by asking isVisible each frame (see the example under showModal).
  • References are not widget ids. addChild, listRow and childRef return object references for those HorizonCode nodes; isVisible on one answers false. From a script a child reference is good for removeChild.
  • Animation ok checks less than it seems. It is false for a missing widget or element, but a property name the element does not have is accepted and animates nothing, and an unknown easing name runs as "Linear". The easings are "Linear", "In Quad", "Out Quad", "In Out Quad", "In Cubic", "Out Cubic", "In Out Cubic" and "Out Back"; directions for the clip rows are "Forward", "Backward" and "Ping Pong" (anything else is Forward). Colours are four numbers, points two: animateColor(w, "Card", "Color", 1, 0, 0, 1, 0.5, "Linear").
  • Lists are named by the element's name in the designer. A negative count becomes 0; an index at or past the count leaves the selection as it was, and still answers true. listRow is 0 for an item that is scrolled out of view.
  • Closing is hiding. After closeTopLayer, Escape or Back, a dialog or popup widget answers isVisible false; show it again to reopen it.
