Reading and writing JSON text without a parser of your own: a config file from File System, a reply from HTTP. Every call takes the whole document as a string. The setters do not change it in place; they return the new document, so keep the result: doc = horizon.json.setNumber(doc, "volume", 0.8).

A path is a chain of keys separated by dots, with [i] for an array element counted from 0: user.name, items[2].id. The empty path is the document itself, so count(text, "") counts a top-level array. A key that itself contains a dot cannot be reached.

  • Getters never fail loudly. A missing path, a value of another type and text that is not JSON all return the fallback. has is true for a key whose value is null.
  • Setters create missing objects along the path, and an empty string starts a new document. They cannot add array elements: a path through a missing index, or through a value that is not an object, returns the document unchanged, as does text that is not JSON.
  • The returned text is compact and its keys come out in alphabetical order, whatever order they had.
  • Numbers pass through a 32-bit float. getNumber is exact for whole numbers up to 16 777 216 and keeps about seven digits otherwise; setNumber writes 3 as 3.0 and 0.1 as 0.10000000149011612. Read ids and other large numbers that the source wrote as strings with getString.
