# Security Policy

## Supported Versions

Only the newest release gets patches. "Supported" means exactly that — security
fixes land on the current version, and older ones are expected to upgrade.

| Version | Supported          |
| ------- | ------------------ |
| 0.3.x   | :white_check_mark: |
| 0.2.x   | :x:                |
| 0.1.x   | :x:                |

## Reporting a Vulnerability

**Please do not open a public issue for a security problem.** An issue is
visible to everyone the moment it is filed, including to anyone who would use
the bug before there is a fix.

Email **info@horizoncreations.dev** instead. Useful things to include, as far as
you have them:

- what the problem is, and what an attacker gets out of it
- the engine version (Help ▸ About, or the editor's window title)
- the steps or the project that triggers it
- anything you already know about how far it reaches

You will get an acknowledgement, and we will tell you when a fix ships and
whether you would like to be credited.

Ordinary bugs — crashes, wrong rendering, anything that is not a security
problem — are very welcome in the issue tracker. The editor has
**Help ▸ Report Issue**, which fills in the version, the machine and the
relevant part of the log for you.
